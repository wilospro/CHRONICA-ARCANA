About

Chronica Arcana is the foundation of the series. It provides the shared systems that every expansion builds on, so all modules work together without stepping on each other. Every module is optional: install only what you want and leave the rest.

Modular by design

Pick the modules you like. Each one adds its own content on top of the core.

One shared foundation

A common base keeps the series consistent and lets modules cooperate.

Open to addons

Addons that depend on Chronica Arcana are explicitly welcome.

The Series

The core comes first. Expansion modules follow, each named as Chronica Arcana: Title.
